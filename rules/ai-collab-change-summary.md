# 변경 요약

목적: 흐름을 따라갈 수 있는 최소 기록을 커밋 단위로 남긴다.

## 구현 전 (1줄)
```
예상: 약 N줄, 파일 M개, 영향: <모듈>
```
- 예상 줄 수 N은 숫자만 `.git/ai-estimate`에 저장한다. 커밋 훅이 실제 증가량과 비교한다.

## 커밋 메시지 본문 (5줄 고정)
```
왜: <요청 또는 문제 한 줄>
결정: <양쪽 문 결정 요약 / 없으면 없음>
새 추상화: <이름 — 존재 이유 / 없으면 없음>
삭제: <삭제한 것 / 없으면 없음>
예상 대비: 예상 N줄 → 실제 K줄, <차이 이유>
```

## 규칙
- 파일 목록과 증감 줄 수는 `git diff --stat`이 제공한다. 직접 쓰지 않는다.
- "새 추상화"가 비어 있지 않으면 리뷰 신호다.
- 리팩토링인데 "삭제"가 없으면 이유를 적는다.
