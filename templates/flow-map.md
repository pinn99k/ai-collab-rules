# 흐름 지도 — 프로젝트 이름

> 상태: 예정 (구현 전) | 실제 (Phase N 끝, YYYY-MM-DD)
> 사람이 작업 중에 읽는 문서 두 장 중 하나다. 왜 그렇게 정했는지는 질문 지도에 있다.

## 한 장 그림
요청 하나가 들어와서 결과가 나갈 때까지. 단계가 나뉘어도 그림은 하나다.
구현 전에는 모듈 이름으로, 구현 뒤에는 실제 파일과 함수 이름으로 쓴다.

```
1. 입구              받는 것
 → 2. 단계 이름      무엇을 무엇으로 바꾸는지
 → 3. 단계 이름      ...
 → 4. 출구           내보내는 것
```
