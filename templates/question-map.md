# 질문 지도 — 단계 이름

> 기준 문서: 과제 원문 · 기획서 · 받은 설계 경로
> 종류: 질문 지도 | 빈칸 지도 (받은 설계가 남긴 것만)
> 상태: 결정 중 | 닫힘 (YYYY-MM-DD)

## 명세 · 받은 설계가 이미 정한 것
- "명세 문장" → 그래서 고를 수 없는 것
- 받은 설계에서 온 것은 문서와 절을 적는다. 다시 묻지 않는다

## 지도
```
Q1. 질문                  ← "명세 문장"       [묻기]
 └ Q2. 질문               (Q1 답에 달림)      [묻기]
Q3. 질문                  ← "명세 문장"       [알려주기] 답 한 줄
Q4. 질문                                      [맡기기] 답 한 줄
```

## 결정 카드
"묻기" 질문마다 1장. 위에서부터 하나씩 닫는다.

### Q1. 질문
- A: 이렇게 하면 → 이런 결과
- B: 저렇게 하면 → 저런 결과
- 추천: A. 이유 한 줄
- 답: 고른 것 · 사람 | 위임 · YYYY-MM-DD
- 이름: 고른 뒤에 붙이는 용어
